**📍 Vector Data Analysis with GeoPandas**


📌 Project Overview

This project demonstrates vector data analysis using GeoPandas on Pennsylvania municipality boundary data.

The goal of this project is to:

Load and explore municipal-level polygon data

Compute geometric attributes (e.g., area in km²)

Visualize spatial distribution using choropleth mapping

Practice geospatial data workflows using Python

This project is built as part of my learning path toward Geospatial Data Engineering / GeoML.



🗂 Dataset

Data Source: Pennsylvania Municipality Boundary Data

Geometry Type: Polygon

Coordinate Reference System:EPSG:4326

🛠 Tech Stack

Python

GeoPandas

Shapely

Matplotlib

Folium



📈 Key Learnings

Importance of correct CRS before calculating area

Difference between geographic and projected coordinate systems

How GeoPandas integrates with Folium for interactive visualization

Basic spatial data processing workflow



🚀 Future Improvements
